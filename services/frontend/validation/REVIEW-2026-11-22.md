## Recorded observations

- Baseline: 21 browser views with 29 layout/style observations.
- After fixes: 21 application views plus 8 real-data views, with zero measured layout
  defects or console messages. Desktop, tablet and phone checks include filters,
  date ranges, sorting, rule popups, case details, reasoning, calibration and audit.
- Real scrape: three official public pages, three HTTP 200 responses and readable
  extracted text. Normal robots and SSRF protections stayed enabled. No retries,
  login, challenge bypass, or paid AI service was used.
- Sources: https://bossa.pl/oferta, https://www.xtb.com/pl/konto-i-oplaty,
  https://www.bm.pkobp.pl/oferta/rachunek-inwestycyjny.
- Replays use the saved HTML through the current extraction and analysis code;
  they do not issue repeated requests to the source sites.
- The local deterministic engine checks all three modules and returns 19 rule rows
  (criterion 12 has parts a and b). These results are engineering observations,
  not verified regulatory decisions or accuracy measurements.
- Matching benchmark: same process, captures and 751 registry entries; one warmup
  and 25 measured iterations per function. Matching alone improved by 8.69–9.03×,
  excluding an approximately 18 ms index build. This is not a whole-engine or
  production-throughput claim. See `matching-benchmark.json` in the AI validation results.

## Local-model workload

The isolated runner uses Ollama v0.13.0, verified against its release SHA-256,
and Qwen2.5 0.5B. It replays the three captured pages twice through six persisted
jobs with two workers. The AI HTTP service, inference, database, evidence archive,
case workflow, exports, audit and notifications execute normally. Only the captured
internet input and worker dispatch boundary are controlled for this simulation.
This small model smoke test does not validate the production Gemma configuration.

Workload results will be recorded after the run completes.

## Remaining limits

- Live preview publication was retried and remains blocked by DNS access to the
  hosting Git service. A private Site was registered but has no published version.
  Its expected address is not evidence of a working site.
- Access to the Mac's installed Ollama endpoint was denied by the session. The
  model workload therefore runs on an isolated CI CPU runner.
- The self-contained real-data HTML contains actual captured results. UI changes
  in that preview stay in memory; it cannot submit new analyses to a running backend.
- This is a three-page extraction and workflow experiment. It does not establish
  recall, precision, visual-page compliance, or sustainable production capacity.

## Reproducibility

`watchit-validation.yml` attaches screenshots and structured results as temporary
artifacts. Commits containing `[live-probe]` opt into at most three public-page
requests. Commits containing `[workload-probe]` opt into the local-model workload.
The workflow has read-only repository access and never writes results back itself.
Reviewed summaries are saved to this branch by the development workflow.
