# Portfolio (demo)

Static site built from vanilla Web Components. No build step, no dependencies.

## Quick Start

```bash
python3 -m http.server 8080 --directory demo/portfolio
```

Open http://localhost:8080.

## Requirements

Python 3 (for the static server) and any modern browser.

## Structure

See `coord/contracts/portfolio.md`. Components live in `components/`, data in `data/projects.json`, tokens in `styles/tokens.css`.
